Scribere is a terminal code editor similar to vim or nano, but built from scratch in C. It is extremely lightweight (around 55kb) and offers a fast, clean editing experience right in your terminal.

### Key Features

- **Undo functionality:** Revert your changes easily with `Ctrl-Z`.
- **Search:** Find text within your files with `Ctrl-F`.
- **Warning System:** Prevents accidental data loss by prompting you if you try to exit with unsaved changes.
- **Syntax Highlighting:** Supports C, Python, JavaScript, Go, Rust, Java, and more out of the box.
- **Lightweight:** Minimal footprint and fast performance.

Fun fact: _Scribere_ means "to write" in Latin.
